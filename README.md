# CS240-HW5
Assembler Project for my CS240 class.

#These programs can be run by first making sure the mips file of fizzbuzz is in the project folder, and by editing the run/debug configurations of both the fizzBuzzAssembler and mhcDIsassembler in Intellij. For the fizzBuzzAssembler class enter the argument as specifically mips6.asm. For the fizzBuzzDisassembler class enter the argument as fizzbuzz.mhc-bin, or the binary file. If you’re not using Intellij, you can run the programs by typing - java fizzBuzzAssembler mips6.asm or java fizzBuzzDisassembler fizzbuzz.mhc-bin.
